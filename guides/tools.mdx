> **Tool Count**: 9 Tools  
> **Service Endpoints**:  
> • **API Key Mode**: China `https://mcp.rollinggo.cn/mcp` / Global `https://mcp.rollinggo.ai/mcp`  
> • **OAuth 2.1 Mode**: China `https://mcp.rollinggo.cn/mcp/hotel` / Global `https://mcp.rollinggo.ai/mcp/hotel`  
> 
> 💡 **China (`cn`) vs Global (`ai`) Core Differences**:
> 1. **Localization Package (`localeParam`)**: Only supported on **Global (`ai`)** endpoints (`localeParam: { currency, language }`, default `USD`, 25 currencies; default `en`, supports `en`/`zh`/`ja`). **China (`cn`)** endpoint is fixed to `zh-CN` and `CNY` (omit `localeParam`).
> 2. **Place Type Enum (`placeType`)**: China endpoint uses Chinese enums (`城市`, `机场`, `景点`, `酒店`, etc.); Global endpoint uses English enums (`city`, `airport`, `point_of_interest`, `hotel`, etc.).
> 3. **Deprecated Fields**: Both editions have fully removed `countryCode` and `nationality`.
> 4. **Contact Email (`contact.email`)**: **Required** for China edition; **Optional** for Global edition (Global requires only `firstName` and `lastName`).
> 5. **Rate Plan Filter (`filter`)**: Fully supported on both China and Global endpoints.
> 6. **Order Cancellation Tools (`preCancelHotelBooking` / `confirmCancelHotelBooking`)**: Parameter structures and two-phase safety mechanisms are identical across both editions with native multilingual feedback.

## 3. getHotelDetail — Get Hotel Details & Room Rate Plans

### Description
Queries all sellable room types for a specific hotel, average per-night rates, and cancellation/modification rules. Supports server-side structured room filtering by meal and cancellation terms.

### Input Parameters (Complete field list 📋)
*`hotelId` and `name` are mutually exclusive; `hotelId` is preferred for high-precision matching.*

| Parameter | Type | Required | Default | Description |
|:---|:---|:---|:---|:---|
| `hotelId` | integer | ⚠️ One of | — | Unique hotel ID [format: int32] |
| `name` | string | ⚠️ One of | — | Hotel name (fuzzy search, used when no ID is available) |
| `dateParam` | object | ❌ | — | Check-in/check-out date bundle |
| `dateParam.checkInDate` | string | ❌ | — | Check-in date, format `YYYY-MM-DD` |
| `dateParam.checkOutDate` | string | ❌ | — | Check-out date, format `YYYY-MM-DD` (must be later than checkInDate) |
| `occupancyParam` | object | ❌ | — | Room count and occupancy constraints |
| `occupancyParam.roomCount` | integer | ❌ | `1` | Number of rooms to book, default 1 [format: int32] |
| `occupancyParam.adultCount` | integer | ❌ | `2` | Adults per room, default 2 [format: int32] |
| `occupancyParam.childCount` | integer | ❌ | `0` | Children per room, default 0 [format: int32] |
| `occupancyParam.childAgeDetails` | integer[] | ❌ | — | Array of children's ages (length must strictly match childCount) |
| `localeParam` | object | ❌ | — | **[Global Edition Only]** Language and currency preferences (China edition is fixed to `CNY`, omit this parameter) |
| `localeParam.language` | string | ❌ | `en` (Global) / `zh-CN` | Language code (e.g., `en`, `zh`, `ja`) |
| `localeParam.currency` | string | ❌ | `USD` (Global) / `CNY` | Settlement currency code (e.g., `USD`, `EUR`, `JPY`, `HKD`, etc. 25 currencies) |
| `filter` | object | ❌ | — | **Room rate plan filtering bundle (returns all plans if omitted; supported on both China & Global)** |
| `filter.mealType` | string | ❌ | — | Meal plan filter, e.g., `"BREAKFAST_INCLUDED"`, `"DOUBLE_BREAKFAST"`, `"NO_MEAL"` (supports EN/ZH/JA, see matrix below) |
| `filter.cancelable` | string | ❌ | — | Cancellation policy filter, e.g., `"CANCELABLE"`, `"NON_CANCELABLE"` (supports EN/ZH/JA, see matrix below) |

#### Multilingual Filter Compatibility Matrix
| Filter Dimension | Matching Logic | Standard Enum (Recommended) | Chinese Aliases | Japanese Aliases |
|:---|:---|:---|:---|:---|
| **Meal Filter** (`mealType`) | `mealAmount > 0` (Breakfast included) | `"BREAKFAST_INCLUDED"` | `"含早餐"`, `"含早"` | `"朝食付き"`, `"朝食あり"` |
| | `mealAmount == 1` (Single breakfast) | `"SINGLE_BREAKFAST"` | `"单份早餐"`, `"单早"` | `"1名朝食付き"` |
| | `mealAmount == 2` (Double breakfast) | `"DOUBLE_BREAKFAST"` | `"双份早餐"`, `"双早"` | `"2名朝食付き"` |
| | `mealAmount == 0` (No meal / Room only) | `"NO_MEAL"` / `"ROOM_ONLY"` | `"不含餐食"`, `"无早"` | `"食事なし"`, `"素泊まり"` |
| **Cancellation Filter** (`cancelable`) | Free cancellation only | `"CANCELABLE"` | `"可免费取消"`, `"免费取消"` | `"無料キャンセル"`, `"キャンセル可能"` |
| | Non-refundable only | `"NON_CANCELABLE"` | `"不可取消"`, `"不可免费取消"` | `"キャンセル不可"` |

## 5. createHotelBookingWithPaymentURL — Create Order with Payment URL

### Description
Submits guest and contact details to generate an active booking order and retrieve cashier payment information.

Based on the client host environment (Web / Browser vs. WeChat / Mini Program), the system returns one of two mutually exclusive payment fields:
1. **`paymentUrl`**: Web payment URL, directly opened in browser to complete checkout;
2. **`miniProgramPayInfo`**: Mini Program payment object, directly launching the native WeChat Mini Program cashier in Mini Program or native APP environments.

* **Strict Mutual Exclusivity**: Only the field matching the current client environment is returned; the other is completely omitted from the response;
* **Non-Pending State Returns null**: If an order is paid, cancelled, or expired, the configured payment field is retained and set to `null`.

### Input Parameters (Complete field list 📋)

| Parameter | Type | Required | Default | Description |
|:---|:---|:---|:---|:---|
| `referenceNo` | string | ✅ | — | Valid referenceNo obtained from price confirmation stage |
| `contact` | object | ✅ | — | Primary order contact person details |
| `contact.firstName` | string | ✅ | — | Contact first name (Pinyin or English) |
| `contact.lastName` | string | ✅ | — | Contact last name (Pinyin or English) |
| `contact.email` | string | ⚠️ | — | Email address for confirmation voucher and invoice. **Required for China edition**; **Optional for Global edition** (Global only requires firstName, lastName). |
| `contact.phone` | string | ✅ | — | Contact phone number for SMS and emergency contact (e.g., `"13800138000"`) |
| `guestList` | array | ✅ | — | List of assigned guests per room; array length must equal room count |
| `guestList[].roomNum` | integer | ✅ | — | Room sequence number starting from `1` [format: int32] |
| `guestList[].guestInfo` | array | ✅ | — | List of guests staying in this room (at least 1 adult required) |
| `guestList[].guestInfo[].firstName` | string | ✅ | — | Guest first name (Pinyin or English) |
| `guestList[].guestInfo[].lastName` | string | ✅ | — | Guest last name (Pinyin or English) |
| `guestList[].guestInfo[].isAdult` | boolean | ✅ | — | Whether guest is an adult (`true`) or child (`false`) |
| `guestList[].guestInfo[].age` | integer | ⚠️ Child required | — | Age of child guest (mandatory if `isAdult` is `false`) [format: int32] |
| `customerRequest` | string | ❌ | — | Special customer requests (e.g., non-smoking, high floor) |

### Output (Complete field list 📋)

| Field | Type | Nullable | Description |
|:---|:---|:---|:---|

| `bookingResult` | object/null | ✅ Yes | Booking confirmation result object (null on failure) |
| `bookingResult.orderNo` | string | ❌ No | Unique order number created by RollingGo system (e.g., `"H178..."`) |
| `bookingResult.paymentType` | string | ❌ No | Payment invocation type (fixed as `"PAYMENT_PAGE"`) |

| `bookingResult.miniProgramPayInfo.type` | string | ❌ No | Payment invocation category description |
| `bookingResult.miniProgramPayInfo.url` | string | ⚠️ Conditional | WeChat launch link / scheme (for external web or APP invocation) |
| `bookingResult.miniProgramPayInfo.appId` | string | ⚠️ Conditional | Target WeChat Mini Program AppID (for cross-program navigation) |
| `bookingResult.miniProgramPayInfo.path` | string | ⚠️ Conditional | Target page path (`"pages/order/token-pay/index"`) |
| `bookingResult.miniProgramPayInfo.query` | string | ⚠️ Conditional | Page query parameters string (`"token=B8ZUZoPx"`) |
| `bookingResult.paymentUrlNote` | string | ❌ No | Payment environment guidance and invocation notes |

## 8. preCancelHotelBooking — Pre-Cancel Booking & Penalty Quote

### Description
Pre-cancels a hotel booking to calculate applicable cancellation penalties and obtain a **10-minute valid** confirmation voucher `confirmId`. This tool must always be called before `confirmCancelHotelBooking`.
* **Operation Hints**: `readOnlyHint: true`, `destructiveHint: false`

### Input Parameters

| Parameter | Type | Required | Description |
|:---|:---:|:---:|:---|
| `orderNo` | string | ✅ | RollingGo unique hotel order ID |

### Output

| Field | Type | Nullable | Description |
|:---|:---:|:---:|:---|
| `success` | boolean | ❌ No | Whether the API call succeeded |
| `code` | integer | ❌ No | Business status code (`2000` = success) |
| `canCancel` | boolean | ❌ No | **Core Decision Flag**: Whether online cancellation is permitted.<br />• `true` when `penaltyAmount == 0` (free cancellation);<br />• `false` when `penaltyAmount > 0` (penalty incurred) or non-refundable. |

## 10. Unified Error Codes & Exception Mapping

| Code (`code`) | HTTP Status | Error Enum | Description | Client / Agent Action |
|:---|:---:|:---|:---|:---|
| `2000` | 200 | `SUCCESS` | Operation succeeded | Render success card and message |
| `6001` | 403 | `BOOKING_FORBIDDEN` | Order does not exist or belongs to another user | Prompt user to check order number |
| `6201` | 400 | `PRICE_CONFIRM_FAILED` | Price verification failed / room sold out | Guide user to search alternative rooms |
| `6207` | 400 | `CONFIRM_ID_EXPIRED` | Cancellation voucher expired (> 10 mins) | Re-invoke `preCancelHotelBooking` for a fresh token |
| `6301` | 400 | `BOOKING_NON_CANCELABLE` | Online cancellation disallowed by policy | Display customer service phone and email |
| `6302` | 502 | `SUPPLIER_CANCEL_FAILED` | Upstream supplier cancellation error | Suggest retry or contact support |
