RollingGo Hotel MCP service complies with standardized JSON-RPC 2.0 contracts, providing **9 core tools** across the entire lifecycle from hotel discovery to checkout, voucher inquiry, and refunds.

---

## Core Tool Matrix

| # | Tool Name | Redirect Mode | Closed-Loop Mode | Key Capability & Scenario |
| :- | :--- | :---: | :---: | :--- |
| 1 | **`getHotelSearchTags`** | ✅ | ✅ | Retrieve platform search tags to extract user preferences |
| 2 | **`searchHotels`** | ✅ | ✅ | Discover candidate hotels, starting rates, bookingUrl, and stateless pagination |
| 3 | **`getHotelDetail`** | ✅ | ✅ | Query room rates and amenities with exact server-side meal and cancellation filters |
| 4 | **`hotelPriceConfirm`** | ❌ | ✅ | Lock price and inventory for 30 mins, returning `referenceNo` and guest profiles |
| 5 | **`createHotelBookingWithPaymentURL`** | ❌ | ✅ | Submit guest info to create booking and return checkout voucher (`paymentUrl` / `miniProgramPayInfo`) |
| 6 | **`searchHotelOrders`** | ❌ | ✅ | Query order summary list (lightweight schema to prevent LLM context bloat) |
| 7 | **`getHotelOrderDetail`** | ❌ | ✅ | Query full order details (voucher number, address, GPS coordinates, front desk phone) |
| 8 | **`preCancelHotelBooking`** | ❌ | ✅ | **Two-phase cancellation quote**: Quotes penalties and issues 10-minute `confirmId` |
| 9 | **`confirmCancelHotelBooking`** | ❌ | ✅ | **Two-phase cancellation execution**: Irreversible execution with `confirmId` and automatic refund |

## 9 Core Tools Schema Specifications

### 1. `getHotelSearchTags` (Search Tags)
* **Purpose**: Helps agents discover all supported feature tags (e.g. WiFi, swimming pool, family-friendly).
* **Key Output**: Array of tag strings.

---

### 2. `searchHotels` (Hotel Search)
* **Purpose**: Discovers hotel candidates by destination, dates, star ratings, and budget.
* **Key Inputs**:
  * `place` (String, Required): Destination or landmark name.
  * `placeType` (String, Required): Landmark type (China node uses Chinese enums; Global node uses English enums: `"City"`, `"Attraction"`, `"Commercial Area"`, `"Train Station"`, `"Airport"`).
  * `checkInParam` (Object, Required): `checkInDate` (YYYY-MM-DD), `stayNights` (Int), `adultCount` (Int).
  * `filterOptions` (Object, Optional): `starRatings` (Array, e.g. `[4.0, 5.0]`).
  * `hotelTags` (Object, Optional): `maxPricePerNight`, `requiredTags`.
  * `size` (Int, Optional): Number of hotels per page (default: 5, range: 1~10).
  * `nextPageToken` (String, Optional): Token for subsequent pagination.
  * `localeParam` (Object, Global Node): `language` and `currency` (supports 25 currencies with real-time conversion).
* **Key Outputs**:
  * `hotelList`: Candidate list with `hotelId`, `hotelName`, `starRating`, `priceInfo`, and `bookingUrl`.
  * `nextPageToken`: Next page token (null when reaching end).

---

### 3. `getHotelDetail` (Room Rates & Amenities)
* **Purpose**: Fetches hotel rooms, photos, amenities, and offers server-side filtering.
* **Key Inputs**:
  * `hotelId` (Int, Required): Hotel identifier.
  * `dateParam` (Object, Required): `checkInDate` and `checkOutDate`.
  * `occupancyParam` (Object, Required): `roomCount` and `adultCount`.
  * `filter` (Object, Optional · Recommended):
    * `mealType`: `"DOUBLE_BREAKFAST"`, `"SINGLE_BREAKFAST"`, `"NO_MEAL"`;
    * `cancelable`: `"CANCELABLE"` (free cancellation).
* **Key Output**: `roomRatePlans` with room descriptions, bed types, meals, and cancellation rules.

---

### 4. `hotelPriceConfirm` (Price & Room Lock · Closed-Loop Only)
* **Purpose**: Guarantees price and room inventory for 30 minutes before booking creation.
* **Key Inputs**: `hotelID`, `ratePlanID`, `numOfRooms`, `dateParam`, `occupancyDetails`.
* **Key Outputs**:
  * `referenceNo`: The unique lock quote reference (must be passed to booking creation);
  * `finalTotalAmount`: Guaranteed final total price;
  * `guestProfile`: Suggested frequent guest profile data.

---

### 5. `createHotelBookingWithPaymentURL` (Booking Creation & Cashier · Closed-Loop Only)
* **Purpose**: Creates an official booking and delivers checkout payment vouchers.
* **Key Inputs**:
  * `referenceNo` (String, Required): Lock reference from `hotelPriceConfirm`.
  * `contact` (Object, Required): Contact name, phone, email.
  * `guestList` (Array, Required): List of guests staying in each room.
* **Key Outputs**:
  * `orderNo`: Official booking identifier.
  * `paymentUrl`: Web cashier checkout URL (delivered for Web hosts).
  * `miniProgramPayInfo`: Native cashier launch parameters (delivered for WeChat hosts).

---

### 6. `searchHotelOrders` (Order Summary List · Closed-Loop Only)
* **Purpose**: Lists user hotel reservations in a lightweight summary schema.
* **Key Inputs**: `status` (Optional, e.g. `"WAITING_PAYMENT"`, `"CONFIRMED"`), `page`, `size`.
* **Key Output**: Order summary list including order number, hotel name, dates, amount, and status.

---

### 7. `getHotelOrderDetail` (Full Order Voucher Details · Closed-Loop Only)
* **Purpose**: Retrieves complete reservation and voucher details.
* **Key Input**: `orderNo` (String, Required).
* **Key Outputs**:
  * `hotelConfirmationNo`: Check-in voucher number.
  * `hotelInfo`: Address, GPS coordinates (`latitude`, `longitude`), phone.
  * `stayInfo`: Dates, room type, meals, guest names.
  * `priceInfo`: Price and payment state (`paymentUrl` is set to null when paid).
  * `policyInfo`: Free cancellation deadline and cancellation terms.

---

### 8. `preCancelHotelBooking` (Two-Phase Cancellation Quote · Closed-Loop Only)
* **Purpose**: Evaluates cancellation penalty and issues a 10-minute confirmation voucher.
* **Key Input**: `orderNo` (String, Required).
* **Key Outputs**:
  * `canCancel` (Boolean): Eligibility for online cancellation.
  * `penaltyAmount` (Float): Calculated penalty (0.00 indicates full refund).
  * `bookingId` (String): Internal booking reference.
  * `confirmId` (String): **10-minute valid cancellation voucher**.

---

### 9. `confirmCancelHotelBooking` (Two-Phase Execution · Closed-Loop Only)
* **Purpose**: Irreversibly cancels reservation using the `confirmId` and initiates refund.
* **Key Inputs**: `orderNo`, `bookingId`, `confirmId`, `description` (Optional).
* **Key Output**: `success: true` confirming cancellation and refund initiation.
