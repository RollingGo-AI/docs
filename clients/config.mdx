This guide covers the complete integration methods for all platforms in the official client matrix, plus Cherry Studio and Cline — **13 clients in total**.

## Prerequisites

- A free API Key (format: `mcp_xxxxxxxxxxxxxxxxxxxxxxxx`). Apply via the [application portal](https://rollinggo.store/apply) and receive approval in 1-3 minutes.
- Service endpoint:
  - **Mainland China node**: `https://mcp.rollinggo.cn/mcp`
  - **Overseas node**: `https://mcp.rollinggo.ai/mcp`
- Authentication format: `Authorization: Bearer YOUR_API_KEY` (or `X-Secret-Key: YOUR_API_KEY`)
- Protocol: `streamable-http` (use `http` for Claude CLI)

---

## 1. Claude Code (Terminal)

```bash
claude mcp add RollingGo-Hotel \
  --transport http \
  --header "Authorization: Bearer YOUR_API_KEY" \
  https://mcp.rollinggo.cn/mcp
```

Or add to project root `.mcp.json`:

```json
{
  "mcpServers": {
    "RollingGo-Hotel": {
      "type": "http",
      "url": "https://mcp.rollinggo.cn/mcp",
      "headers": {
        "Authorization": "Bearer YOUR_API_KEY"
      }
    }
  }
}
```

---

## 2. Cursor / Windsurf / Trae

Create `.cursor/mcp.json` or `.windsurf/mcp.json` in your project root:

```json
{
  "mcpServers": {
    "RollingGo-Hotel": {
      "url": "https://mcp.rollinggo.cn/mcp",
      "type": "streamable-http",
      "headers": {
        "Authorization": "Bearer YOUR_API_KEY"
      }
    }
  }
}
```

---

## 3. Codex

In `.codex/config.toml` or `~/.codex/config.toml`:

```toml
[mcp_servers.RollingGo-Hotel]
url = "https://mcp.rollinggo.cn/mcp"
http_headers = { "Authorization" = "Bearer YOUR_API_KEY" }
```

---

## 4. Cherry Studio

1. Open **Settings → MCP Servers → Add**.
2. Select type **HTTP**, set URL to `https://mcp.rollinggo.cn/mcp`.
3. Set Authentication to **Bearer** and paste your API Key.

---

## 5. Cline (VS Code Extension)

In VS Code `settings.json`:

```json
{
  "cline.mcp.servers": [
    {
      "name": "RollingGo-Hotel",
      "type": "http",
      "url": "https://mcp.rollinggo.cn/mcp",
      "headers": {
        "Authorization": "Bearer YOUR_API_KEY"
      },
      "enabled": true
    }
  ]
}
```

---

## 6. Verification and Testing
