# RollingGo Hotel MCP Update — 2026-07-30

**[Announcement] New Admin Dashboard Configuration Capabilities Released**

**Details:**

### 1. Booking URL Toggle
Control whether MCP hotel search results include booking links (`bookingUrl`), which can be enabled or disabled as needed.

### 2. Price Inquiry Settings
Configure price query modes (real-time vs. cached) and timeout policies:
- **Real-Time Price Inquiry Enabled**: Configure optimal timeout (recommended: 3000ms) and maximum timeout (recommended: 10000ms).
- **Disabled**: Configure non-real-time optimal timeout and maximum timeout (e.g., Baidu: optimal 300ms, max 800ms; Yuanbao: optimal 800ms, max 1000ms).

### 3. Client Configuration
Configure Client ID and License Key credentials required to integrate with the RollingGo Hotel API. Unconfigured organization accounts display an "Unconfigured" status, defaulting to the `cookelvyou` organization code.
