本接口用于将搜索得到的可订房型/票务选项转化为确定订单。系统在底层实时调用供应商或航司分销系统锁定库存，并返回支付信息或订单确认编号。

## 1. 发起预订 (POST /v1/travel/book)

```http
POST /v1/travel/book
Authorization: Bearer YOUR_API_KEY
Content-Type: application/json
```

### 请求体示例

```json
{
  "hotelId": "ht_hz_001",
  "roomId": "rm_king_lakeview",
  "checkInDate": "2026-11-01",
  "checkOutDate": "2026-11-03",
  "guests": [
    {
      "name": "张三",
      "mobile": "13800000000"
    }
  ],
  "contactEmail": "zhangsan@example.com"
}
```

### 响应体示例

```json
{
  "status": "ok",
  "data": {
    "bookingId": "bk_20261101_882910",
    "orderStatus": "CONFIRMED",
    "totalPrice": {
      "amount": 1960,
      "currency": "CNY"
    },
    "confirmationNumber": "HY9812401",
    "checkInDate": "2026-11-01",
    "checkOutDate": "2026-11-03"
  },
  "requestId": "req_book_112233"
}
```

## 2. 查询订单状态 (GET /v1/travel/booking/{id})

```http
GET /v1/travel/booking/bk_20261101_882910
Authorization: Bearer YOUR_API_KEY
```
