Webhooks 允许您的服务在发生重要订单事件时（例如酒店确认接单、出票成功或用户发起退改）实时接收 RollingGo 的异步推送通知，无需频繁轮询轮查。

## 注册 Webhook 端点

```http
POST /v1/webhooks/register
Authorization: Bearer YOUR_API_KEY
Content-Type: application/json
```

```json
{
  "url": "https://your-api.com/webhooks/rollinggo",
  "events": ["booking.confirmed", "booking.cancelled", "order.refunded"],
  "secret": "whsec_your_custom_secret"
}
```

## 事件通知回调格式

当事件触发时，RollingGo 将向您注册的 URL 发起 HTTP POST 请求：

```json
{
  "event": "booking.confirmed",
  "timestamp": 1792649000,
  "data": {
    "bookingId": "bk_20261101_882910",
    "status": "CONFIRMED",
    "updatedAt": "2026-11-01T10:05:00Z"
  }
}
```

## 签名校验

每次 Webhook 请求均在 Header 中包含 `X-RollingGo-Signature` 字段，使用您注册时提供的 secret 计算 HMAC-SHA256 签名，保障通知来自官方且未遭篡改。
