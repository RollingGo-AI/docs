通过 `/travel/search` 接口查询符合条件的酒店与机票方案。支持目的地城市、入住/离店日期、房型等级、价格区间等多维度筛选，并返回标准化的实时比价结果。

## 请求地址与方法

```http
POST /v1/travel/search
```

## 请求头参数

| 请求头 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `Authorization` | string | 是 | `Bearer YOUR_API_KEY` |
| `Content-Type` | string | 是 | 必须为 `application/json` |

## 请求体参数示例

```json
{
  "type": "hotel",
  "city": "杭州",
  "checkInDate": "2026-11-01",
  "checkOutDate": "2026-11-03",
  "guests": 2,
  "starRating": [4, 5],
  "minPrice": 300,
  "maxPrice": 1200,
  "keywords": "西湖 湖景"
}
```
