所有对 RollingGo REST API 与 MCP 服务的受保护请求，都必须通过 HTTP 请求头部的 `Authorization` 字段进行身份验证。

## Bearer Token 鉴权格式

在每次 HTTP 请求的头部添加：

```http
Authorization: Bearer <YOUR_API_KEY>
```

例如使用 cURL 发起调用：

```bash
curl -X POST https://api.rollinggo.cn/v1/travel/search \
  -H "Authorization: Bearer rg_live_xxxxxxxxxxxxxxxxxxxx" \
  -H "Content-Type: application/json" \
  -d '{"city": "杭州", "checkInDate": "2026-11-01", "checkOutDate": "2026-11-03"}'
```

## 常见鉴权错误码

| HTTP 状态码 | 错误代码 (code) | 原因与处理建议 |
| --- | --- | --- |
| `401 Unauthorized` | `unauthorized` | 请求未携带 `Authorization` 头，或 API Key 格式不合规。 |
| `401 Unauthorized` | `invalid_token` | API Key 无效或已被后台吊销/轮换。请检查控制台秘钥状态。 |
| `403 Forbidden` | `forbidden` | 账号所属地域与请求 API 域名不匹配，或当前套餐无此接口权限。 |
