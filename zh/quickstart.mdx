获取 RollingGo 酒旅 MCP 产品与接口接入仅需 5 步，耗时不到 5 分钟。选择身份、锁定地域、填写简表并通过邮箱验证码校验，提交瞬间凭证直接展示在屏幕上。无需排队审核，零等待。

## 入驻流程

<Steps>
  <Step title="选择合作身份">
    访问 [合作伙伴中心首页](https://rollinggo.store/zh) 并点击符合您业务场景的卡片：**企业合作**、**开发者**、**KOL / 分销达人** 或 **个人用户**。每类卡片将直接唤起对应的注册表单。详细对比请参阅 [平台介绍](/zh/introduction)。
  </Step>
  <Step title="选择所属地域">
    选择 **中国大陆**（`rollinggo.cn` / 人民币结算）或 **国际 / 港澳台**（`rollinggo.ai` / 美元结算）。此选择提交后永久绑定，决定了控制台域名、账单币种及邮件网关，请谨慎确认。
  </Step>
  <Step title="填写注册信息">
    按所选身份填写简明资料。常见字段包括联系人姓名、企业/团队名称（如适用）、联系邮箱及预计应用场景。
  </Step>
  <Step title="邮箱验证码校验">
    输入接收到的 6 位邮箱一次性动态验证码（OTP）。发件人为 `partner@rollinggo.cn` 或 `partner@rollinggo.ai`。若未收到请检查垃圾邮件箱。
  </Step>
  <Step title="即时获取凭证">
    点击 **提交**。系统全自动秒级审核通过，页面将立即生成并展示您的专属凭证（API Key、H5 推广链接或智能体配置文件）。离开页面前请妥善复制保存。
  </Step>
</Steps>

## 凭证产物对照

不同合作身份在激活后获取的接入物有所不同，详见下表：

| 合作身份 | 获取的凭证与产物 | 是否创建管理账号 |
| --- | --- | --- |
| 企业合作 (Enterprise) | API Key + MCP 接入配置参数 | 是 —— 即时激活并发送初始密码 |
| 开发者 (Developer) | API Key | 是 —— 即时激活并发送初始密码 |
| KOL / 分销达人 | 专属 H5 分销链接 + 达人看板 | 是 —— 即时激活 |
| 个人用户 (Personal) | 一键配置包 + 安装命令 | 否（免注册即用） |

<Tip>
  **企业合作与开发者伙伴：** 提交成功后，系统会自动发送一封包含初始登录密码的欢迎邮件，请使用该密码登录合作伙伴管理后台。
</Tip>
