**更新于：2026-08-12** | **文档版本：v1.0** 

> **面向：** 第三方开发者、AI Agent 构建者、MCP 客户端用户

## ⚡ 30 秒概览

RollingGo 提供两类 [Model Context Protocol(MCP)](https://modelcontextprotocol.io/docs/2026-07-28/getting-started/intro) 服务：

| 服务 | 端点 | 已上线 Tool | 状态 | 认证方式 |
| :--- | :--- | :--- | :---: | :--- |
| **酒店 MCP** | `https://mcp.rollinggo.cn/mcp` | `searchHotels` / `getHotelDetail` / `getHotelSearchTags` (共 3 个) | ✅ **正常运营** | `Authorization: Bearer YOUR_API_KEY` |
| **机票 MCP** | `https://mcp.rollinggo.cn/mcp/flight` | `searchAirports` / `searchFlights` (共 2 个) | ⚠️ **已下线** | `Authorization: Bearer YOUR_API_KEY` |

> ⚠️ **业务变更说明**：机票 MCP 业务 (`searchAirports` / `searchFlights`) 目前已暂停下线维护。推荐使用并接入主推的酒店 MCP 服务。以下配置与示例保留供参考。

**传输协议：** `streamable-http` / `http`

## 🚀 快速接入步骤

### 第一步：选择身份注册

1. 访问 [https://rollinggo.store/apply](https://rollinggo.store/apply)
2. 根据你的使用场景选择 **四大业务身份卡片** 之一：
   * **开发者 (Developer)**：已有或正在开发智能体/旅行程序，接入 MCP 服务（推荐开发者使用）
   * **企业 (Enterprise)**：企业主体申请接入，面向企业员工差旅或外部客户
   * **个人 (Personal)**：使用个人 AI 工具（OpenClaw / Claude Code / Codex / Cursor / WorkBuddy 等）极速免账号体验
   * **达人分销 (KOL)**：有推广渠道，通过 H5 / 小程序进行分销变现
3. 选择所属服务区域：
   * **中国大陆**：绑定 `rollinggo.cn` 节点与人民币 (CNY) 结算
   * **海外及港澳台**：绑定 `rollinggo.ai` 节点与美元 (USD) 结算

1. **全员秒级过审**：Partner 2.0 支持系统自动秒过，无任何人工审核卡点。

### 第三步：接入 Agent 工具

> 推荐 **Claude CLI**、**Codex**、**Cursor** 三个客户端。其他支持 MCP 的客户端（如 Kiro、豆包、Dify 等）配置方式类似。

#### 1. Claude CLI / Claude Desktop

在项目根目录创建 `.mcp.json`：

```json
{
  "mcpServers": {
    "RollingGo-Hotel": {
      "url": "https://mcp.rollinggo.cn/mcp",
      "type": "http",
      "headers": {
        "Authorization": "Bearer YOUR_API_KEY"
      }
    },
    "RollingGo-Flight": {
      "url": "https://mcp.rollinggo.cn/mcp/flight",
      "type": "http",
      "headers": {
        "Authorization": "Bearer YOUR_API_KEY"
      }
    }
  }
}
```

也可以通过 CLI 命令行直接添加：

```bash
claude mcp add \
  --transport http \
  --header "Authorization: Bearer YOUR_API_KEY" \
  RollingGo-Hotel \
  https://mcp.rollinggo.cn/mcp
```

```bash
# ⚠️ 注意：机票 MCP 当前已下线维护
claude mcp add \
  --transport http \
  --header "Authorization: Bearer YOUR_API_KEY" \
  RollingGo-Flight \
  https://mcp.rollinggo.cn/mcp/flight
```

#### 4. cURL 直接测试

```bash
  -H "Content-Type: application/json" \

  -H "Authorization: Bearer YOUR_API_KEY" \

        "placeType": "景点",

          "checkInDate": "2026-08-15",
          "stayNights": 2
        },
        "filterOptions": {
          "starRatings": [5.0]
        },
        "size": 3
      }
    },
    "id": 1
  }'
```

## 📚 附录与进阶指南

### 💡 推荐调用流程 (v1.0)

#### 1. 酒店搜索
1. 用户说“帮我订酒店”。
2. 调用 `getHotelSearchTags` → 引导用户选择偏好（五星 / 泳池 / 含早 / 可取消）。
3. 调用 `searchHotels` → 返回候选酒店列表。
4. 用户选定 → 调用 `getHotelDetail` → 返回房型和价格（仅供展示与参考）。

#### 2. 机票查询（⚠️ 已下线）
1. 调用 `searchAirports` → 获取城市代码。
2. 调用 `searchFlights` → 返回航班列表。（注：机票服务目前已下线维护）

## ❓ 常见问题 (FAQ)

### Q1：配置后客户端看不到 Tool
1. 检查 `.mcp.json` / `config.json` 的语法是否正确。
2. 确认 `url` 和 `type` 是否匹配服务端要求。
3. 确认 `Authorization` header 中的 API Key 是否填写正确。
4. **保存配置后需重启 Agent 客户端生效**。

### Q2：返回 401 Unauthorized
API Key 无效或格式不全：
1. 确认 API Key 包含了前缀 `mcp_`。
2. `Authorization: Bearer YOUR_API_KEY` 中 `Bearer` 后面需包含空格。
3. 检查环境变量或配置文件中是否有首尾多余的换行符。

### Q3：返回 400 Bad Request
cURL 直接调用时常见，必须包含 `Accept` 请求头：
```bash
-H "Accept: application/json, text/event-stream"
```

### Q4：searchHotels 返回空结果
1. 检查 `place` 和 `placeType` 是否匹配（如“上海外滩”设为“景点”）。
2. 适当放宽筛选条件（如删减星级或强性标签限制）。
3. 确认 `checkInDate` 为未来日期。

### Q5：searchFlights / 机票接口报错？
机票 MCP 服务 (`/mcp/flight`) 目前已暂停下线维护。若尝试调用会返回 404 或下线提示，请接入酒店 MCP 服务。

### Q6：价格和实际不一致？
搜索结果中的价格是参考价，实时价格可能有变动。初级版本（v1.0）仅支持信息查询与展示，暂不支持在线下单。

### Q7：如何免费获取 API Key？
前往 [https://rollinggo.store/apply](https://rollinggo.store/apply) 选择身份提交申请，秒级自动审核过审，前端页面即时展现 API Key。
