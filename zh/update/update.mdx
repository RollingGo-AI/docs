# RollingGo酒店MCP更新 2026-07-30
【公告】后台管理系统新增配置能力上线

具体说明：
1. 是否返回酒店预定链接
控制MCP酒店搜索结果中是否携带预定链接（bookingUrl），可按需开启/关闭。


2. 查价配置
控制MCP酒店搜索的查价模式（实时 / 非实时）及对应的超时策略：
开启「是否实时查价」后，需配置实时查价最优超时时间（建议3000）和实时查价最大超时时间（建议10000）
关闭时，需配置非实时查价最优超时时间和非实时查价最大超时时间（根据客户要求填写，百度是最优 300ms，最大 800ms，元宝是最优 800ms，最大 1000ms）


3. 客户端配置
用于配置对接RollingGo Hotel API所需的 Client ID 和 License Key，作为接口鉴权凭证。未配置的机构号会显示"未配置"状态，默认使用cookelvyou机构号。
