API Key 是企业合作与开发者调用 RollingGo 酒旅 MCP 及 REST API 接口的核心鉴权凭据。注册表单提交成功后，秘钥将直接在成功结果页中完整显示一次，请务必立即复制并安全保存。

## 获取与查看 API Key

您可以在以下两个入口获取或管理您的 API Key：

<CardGroup cols={2}>
  <Card title="入驻成功结果页" icon="circle-check">
    提交表单后，页面立即展示您的初始 API Key。这是复制保存最直接的途径。
  </Card>

  <Card title="合作伙伴控制台" icon="key">
    登录控制台并进入 **设置 → API Key 管理**，可随时查看秘钥列表、生成新秘钥或吊销旧秘钥。
  </Card>
</CardGroup>

## 请求鉴权方式

在调用 RollingGo API 接口时，请在 HTTP 请求头部的 `Authorization` 字段中以 Bearer Token 形式携带您的 API Key：

```http
POST https://api.rollinggo.cn/v1/travel/search
Authorization: Bearer YOUR_API_KEY
Content-Type: application/json
```

<Note>
  **中国大陆账号** 请使用 `api.rollinggo.cn` 域名；**国际 / 港澳台账号** 请使用 `api.rollinggo.ai` 域名。
</Note>

### 通过环境变量加载秘钥

严禁在前端或客户端硬编码秘钥。请始终将 API Key 存放于服务端环境变量中：

```bash
export ROLLINGGO_API_KEY="rg_live_xxxxxxxxxxxxxxxxxxxx"
```

在后端代码中引用：

```javascript
const apiKey = process.env.ROLLINGGO_API_KEY;

const response = await fetch('https://api.rollinggo.cn/v1/travel/search', {
  method: 'POST',
  headers: {
    'Authorization': `Bearer ${apiKey}`,
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({ query: '杭州西湖附近的五星级酒店' })
});
```

## 安全最佳实践

<AccordionGroup>
  <Accordion title="严禁将秘钥泄露至前端代码或公开代码仓库">
    请勿将 API Key 写入前端 React / Vue 代码或提交到 GitHub 公开仓库。所有持有 API Key 的调用必须发生在受信任的后端服务器上。
  </Accordion>

  <Accordion title="区分测试环境与生产环境秘钥">
    在控制台中为测试环境与正式生产环境分别生成独立的 API Key，避免测试意外影响线上业务与账单。
  </Accordion>

  <Accordion title="发生泄露立即轮换">
    若怀疑秘钥遭到泄露，请立即登录控制台点击“重新生成”，旧秘钥将被即刻作废。
  </Accordion>
</AccordionGroup>
