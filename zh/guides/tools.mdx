## 核心 Tool 矩阵总览

| # | Tool 名称 | 跳转模式 | 闭环模式 | 核心能力与业务场景 |
| :- | :--- | :---: | :---: | :--- |
| 1 | **`getHotelSearchTags`** | ✅ | ✅ | 获取平台全量支持的酒店特色标签，用于提炼偏好并构建精确搜索条件 |
| 2 | **`searchHotels`** | ✅ | ✅ | 酒店初筛搜索，返回候选列表、参考起价、预订直链及无状态翻页凭证 |
| 3 | **`getHotelDetail`** | ✅ | ✅ | 查询房型套餐与设施详情，支持服务端餐食与退改精准筛选 |
| 4 | **`hotelPriceConfirm`** | ❌ | ✅ | 实时库存校验与总价锁定（30 分钟），生成 `referenceNo` 与智能旅客画像 |
| 5 | **`createHotelBookingWithPaymentURL`** | ❌ | ✅ | 提交住客信息生单，下发安全收银台支付凭证（`paymentUrl` / `miniProgramPayInfo`） |
| 6 | **`searchHotelOrders`** | ❌ | ✅ | 查询名下历史订单列表与概要信息（轻量出参，防止模型上下文膨胀） |
| 7 | **`getHotelOrderDetail`** | ❌ | ✅ | 查询单笔订单完整详情（含入离凭证号、物理地址、导航坐标、联系电话） |
| 8 | **`preCancelHotelBooking`** | ❌ | ✅ | **两阶段预取消试算**：试算取消罚金，派发 10 分钟有效的凭证 `confirmId` |
| 9 | **`confirmCancelHotelBooking`** | ❌ | ✅ | **两阶段确认取消执行**：携带 `confirmId` 执行不可逆取消并原路退款 |

## 1. getHotelSearchTags — 获取搜索标签

### 功能说明

获取所有启用的酒店筛选标签。

### Input 参数

无。

### Output 输出

| 字段                          | 类型    | 能否为空 | 说明                                                  |
| :---------------------------- | :------ | :------- | :---------------------------------------------------- |
| `success`                   | boolean | ❌ 否    | 接口是否执行成功                                      |
| `tags`                      | array   | ❌ 否    | 标签数据列表                                          |
| `tags[].name`               | string  | ❌ 否    | 标签展示名称（如`"免费WiFi"`、`"当地连锁"` 等）   |
| `tags[].category`           | string  | ❌ 否    | 标签所属分类（如`"景观与房型"`、`"核心设施"` 等） |
| `usageGuide`                | object  | ❌ 否    | 大模型使用过滤偏好指导                                |
| `usageGuide.tagUsage`       | string  | ❌ 否    | 标签在请求体中的组合绑定指南文字                      |
| `usageGuide.exampleRequest` | string  | ❌ 否    | 包含标签筛选的完整请求 JSON 示例字符串                |

## 2. searchHotels — 搜索全球酒店

### 功能说明

根据筛选条件在指定的限定区域进行全球酒店初筛，返回候选酒店列表及展示用首夜预估最低零售价。

### Input 参数（全部字段 📋）

| 参数                              | 类型     | 必填 | 默认值                      | 说明                                                                                                                                                                                                                                                                                                         |
| :-------------------------------- | :------- | :--- | :-------------------------- | :----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `originQuery`                   | string   | ✅   | —                          | 针对多轮会话提炼出的完整住宿意图描述文本                                                                                                                                                                                                                                                                     |
| `place`                         | string   | ✅   | —                          | 目标搜索名称（地名/机场/景点/车站/具体酒店名等）                                                                                                                                                                                                                                                             |
| `placeType`                     | string   | ✅   | —                          | 地点类型。**国内版**使用中文枚举（`城市`、`机场`、`景点`、`火车站`、`地铁站`、`酒店`、`区/县`、`详细地址`）；**国际版**使用英文枚举（`city`、`airport`、`point_of_interest`、`train_station`、`subway_station`、`hotel`、`district/county`、`detailed address`） |
| `checkInParam`                  | object   | ❌   | —                          | 入住及入住晚数信息包                                                                                                                                                                                                                                                                                         |
| `checkInParam.checkInDate`      | string   | ❌   | 明天                        | 入住开始时间，格式`YYYY-MM-DD`                                                                                                                                                                                                                                                                             |
| `checkInParam.stayNights`       | integer  | ❌   | `1`                       | 入住晚数（范围为`1` ~ `28`） [format: int32]                                                                                                                                                                                                                                                             |
| `checkInParam.adultCount`       | integer  | ❌   | `2`                       | 每间房屋成人数 [format: int32]                                                                                                                                                                                                                                                                               |
| `localeParam`                   | object   | ❌   | —                          | **【仅国际版支持】** 语言与币种偏好包（国内版固定中文+CNY，无需传入；替代原 countryCode）                                                                                                                                                                                                              |
| `localeParam.language`          | string   | ❌   | `en`（国际版）/ `zh-CN` | 语言代码（如`en`、`zh`、`ja`）                                                                                                                                                                                                                                                                         |
| `localeParam.currency`          | string   | ❌   | `USD`（国际版）/ `CNY`  | 结算币种代码（如`USD`、`EUR`、`JPY`、`HKD` 等 25 种国际货币）                                                                                                                                                                                                                                        |
| `filterOptions`                 | object   | ❌   | —                          | 地理解析及星级过滤层配置                                                                                                                                                                                                                                                                                     |
| `filterOptions.distanceInMeter` | integer  | ❌   | `2000`                    | 直线物理距离限制（米），placeType 为景点/机场时生效 [format: int32]                                                                                                                                                                                                                                          |
| `filterOptions.starRatings`     | float[]  | ❌   | `[0.0, 5.0]`              | 星级范围数组，取值 0.0-5.0（步长为 0.5）                                                                                                                                                                                                                                                                     |
| `hotelTags`                     | object   | ❌   | —                          | 高级标签、品牌及预算限制级过滤包                                                                                                                                                                                                                                                                             |
| `hotelTags.requiredTags`        | string[] | ❌   | —                          | 必须满足的硬性条件标签列表                                                                                                                                                                                                                                                                                   |
| `hotelTags.preferredBrands`     | string[] | ❌   | —                          | 连锁品牌名称偏好列表                                                                                                                                                                                                                                                                                         |
| `hotelTags.maxPricePerNight`    | float    | ❌   | —                          | 每房每晚的预算本币价格上限（按所传 currency 币种理解）                                                                                                                                                                                                                                                       |
| `size` | integer | ❌ | `5` | 返回的酒店数量限制（默认`5`，最大不超过`10`），翻页时按当次请求动态生效 [format: int32] |
| `nextPageToken` | string | ❌ | `null` | 分页游标。仅当获取下一页（“换一批”）时，原样回传上一页返回的 `nextPageToken`；首页查询不传。传入有效 Token 时，核心检索条件以 Token 内快照为准 |

### Output 输出

#### 顶层字段

| 字段                     | 类型    | 能否为空 | 说明                       |
| :----------------------- | :------ | :------- | :------------------------- |
| `success`              | boolean | ❌ 否    | 查询是否成功               |
| `message`              | string  | ❌ 否    | 业务层处理反馈消息         |
| `nextPageToken` | string/null | ✅ 是 | 下一页分页游标。存在更多候选酒店且未达翻页上限时返回加密串；候选池查完或达到探测上限时返回 `null` |

| `latitude`          | double       | ❌ 否    | 酒店地理位置纬度（WGS-84标准）                                                   |
| `longitude`         | double       | ❌ 否    | 酒店地理位置经度（WGS-84标准）                                                   |
| `starRating`        | number       | ❌ 否    | 酒店评级星级（1-5级）                                                            |

## 3. getHotelDetail — 获取酒店详情与房型报价

### 功能说明

查询特定酒店所有可售房型、间夜均价以及对应的退改规则。支持在服务端按餐食（`mealType`）与免费取消（`cancelable`）进行精准过滤。

### Input 参数（全部字段 📋）

*`hotelId` 与 `name` 二选一，优先使用 `hotelId` 进行高精度命中。*

| 参数                               | 类型      | 必填        | 默认值                      | 说明                                                                            |
| :--------------------------------- | :-------- | :---------- | :-------------------------- | :------------------------------------------------------------------------------ |
| `hotelId`                        | integer   | ⚠️ 二选一 | —                          | 酒店唯一ID [format: int32]                                                      |
| `name`                           | string    | ⚠️ 二选一 | —                          | 酒店名称（模糊搜索，无 ID 时使用）                                              |
| `dateParam`                      | object    | ❌          | —                          | 入离店日期配置包                                                                |
| `dateParam.checkInDate`          | string    | ❌          | —                          | 入住日期，格式`YYYY-MM-DD`                                                    |
| `dateParam.checkOutDate`         | string    | ❌          | —                          | 离店日期，格式`YYYY-MM-DD`（必须晚于 checkInDate）                            |
| `occupancyParam`                 | object    | ❌          | —                          | 房间间数及住宿名额约束                                                          |
| `occupancyParam.roomCount`       | integer   | ❌          | `1`                       | 拟预订间数 [format: int32]                                                      |
| `occupancyParam.adultCount`      | integer   | ❌          | `2`                       | 每间拟入住成人数 [format: int32]                                                |
| `occupancyParam.childCount`      | integer   | ❌          | `0`                       | 每间拟入住儿童数 [format: int32]                                                |
| `occupancyParam.childAgeDetails` | integer[] | ❌          | —                          | 儿童年龄数组（长度须与 childCount 严格对齐）                                    |
| `localeParam`                    | object    | ❌          | —                          | **【仅国际版支持】** 语言与币种偏好包（国内版固定人民币 CNY，无需传入）   |
| `localeParam.language`           | string    | ❌          | `en`（国际版）/ `zh-CN` | 语言代码（如`en`、`zh`、`ja`）                                            |
| `localeParam.currency`           | string    | ❌          | `USD`（国际版）/ `CNY`  | 币种代码（如`USD`、`EUR`、`JPY`、`HKD` 等 25 种国际货币）               |
| `filter`                         | object    | ❌          | —                          | **房型筛选条件包（未传或为空时返回全量房型，国内版与国际版均支持）**      |
| `filter.mealType`                | string    | ❌          | —                          | 餐食类别筛选，如`"含早餐"`、`"单份早餐"`、`"双份早餐"`、`"不含餐食"` 等 |
| `filter.cancelable`              | string    | ❌          | —                          | 退改政策筛选，如`"可免费取消"`、`"不可取消"` 等                             |

#### 房型筛选多语言输入兼容矩阵

| 筛选维度                            | 业务逻辑                    | 标准英文枚举（推荐）            | 中文兼容别名                       | 日文兼容别名                               |
| :---------------------------------- | :-------------------------- | :------------------------------ | :--------------------------------- | :----------------------------------------- |
| **餐食筛选** (`mealType`)   | `mealAmount > 0`（含早）  | `"BREAKFAST_INCLUDED"`        | `"含早餐"`, `"含早"`           | `"朝食付き"`, `"朝食あり"`             |
|                                     | `mealAmount == 1`（单早） | `"SINGLE_BREAKFAST"`          | `"单份早餐"`, `"单早"`         | `"1名朝食付き"`                          |
|                                     | `mealAmount == 2`（双早） | `"DOUBLE_BREAKFAST"`          | `"双份早餐"`, `"双早"`         | `"2名朝食付き"`                          |
|                                     | `mealAmount == 0`（无早） | `"NO_MEAL"` / `"ROOM_ONLY"` | `"不含餐食"`, `"无早"`         | `"食事なし"`, `"素泊まり"`             |
| **退改筛选** (`cancelable`) | 仅可免费取消                | `"CANCELABLE"`                | `"可免费取消"`, `"免费取消"`   | `"無料キャンセル"`, `"キャンセル可能"` |
|                                     | 仅不可免费取消              | `"NON_CANCELABLE"`            | `"不可取消"`, `"不可免费取消"` | `"キャンセル不可"`                       |

| `hotelId`         | integer | ❌ 否    | 酒店 ID 标识                                                                    |

## 4. hotelPriceConfirm — 价格确认与锁价

### 功能说明

锁定选定房型的实时最终价格，获取预订参考流水号 `referenceNo`，锁定有效期 30 分钟。同时返回预填常住旅客画像 `guestProfile`。

### Input 参数（全部字段 📋）

## 9. confirmCancelHotelBooking — 确认并执行订单取消

### 功能说明

使用 `preCancelHotelBooking` 返回的 `confirmId` 和 `bookingId` 确认并执行酒店订单的最终取消。此操作不可逆，调用前必须获得用户的明确确认。

* **操作特性**：`readOnlyHint: false`, `destructiveHint: true`, `idempotentHint: true`

### Input 参数

| 参数名          |  类型  | 必填 | 说明                                                                          |
| :-------------- | :----: | :--: | :---------------------------------------------------------------------------- |
| `orderNo`     | string |  ✅  | `preCancelHotelBooking` 返回的订单号                                        |
| `bookingId`   | string |  ✅  | `preCancelHotelBooking` 返回的预订号（`bookingId`）                       |
| `confirmId`   | string |  ✅  | `preCancelHotelBooking` 返回的取消确认凭证（`confirmId`，有效期 10 分钟） |
| `description` | string |  ❌  | 可选的取消原因或备注说明                                                      |

### Output 输出

| 字段        |  类型  | 能否为空 | 说明                            |
| :---------- | :-----: | :------: | :------------------------------ |
| `success` | boolean |  ❌ 否  | 订单是否取消成功                |
| `code`    | integer |  ❌ 否  | 业务状态码（`2000` 表示成功） |
| `message` | string |  ❌ 否  | 取消结果提示文案                |
| `orderNo` | string |  ❌ 否  | 已成功取消的订单号              |

#### `message` 字段中/英/日规则

* **中文 (`zh-CN`)**：`“订单 ${orderNo} 已成功取消。”`
* **英文 (`en`)**：`"Booking ${orderNo} has been successfully cancelled."`
* **日文 (`ja`)**：`"予約 ${orderNo} のキャンセルが完了しました。"`

#### 输出示例

```json
{
  "success": true,
  "code": 2000,
  "message": "订单 H178969795522549201 已成功取消。",
  "orderNo": "H178969795522549201"
}
```
