本指南指导您将 RollingGo 酒旅 MCP 服务无缝挂载到您日常使用的 AI 编程助手或个人 Agent 中，让大模型在聊天过程中直接具备实时查房价、比对酒店设施与推荐出游方案的能力。

## 支持的客户端与配置方式

<Tabs>
  <Tab title="Cursor">
    1. 打开 Cursor 设置面板 (`Settings` / `Preferences`)。<br/>
    2. 进入 **Features → MCP Servers** 页面。<br/>
    3. 点击 **+ Add New MCP Server**，选择类型为 `command` 或 `sse`：

    ```json
    {
      "mcpServers": {
        "rollinggo-hotel": {
          "command": "npx",
          "args": ["-y", "@rollinggo/mcp-hotel"],
          "env": {
            "ROLLINGGO_API_KEY": "YOUR_API_KEY"
          }
        }
      }
    }
    ```
  </Tab>

  <Tab title="Claude Desktop / Claude Code">
    在您的 Claude Desktop 配置文件 `claude_desktop_config.json` 中添加：

    ```json
    {
      "mcpServers": {
        "rollinggo-travel": {
          "command": "npx",
          "args": ["-y", "@rollinggo/mcp-hotel"],
          "env": {
            "ROLLINGGO_API_KEY": "YOUR_API_KEY"
          }
        }
      }
    }
    ```
  </Tab>

  <Tab title="OpenClaw / CLI">
    执行一键安装指令：

    ```bash
    openclaw plugin install rollinggo-hotel --api-key YOUR_API_KEY
    ```
  </Tab>
</Tabs>

## 验证与测试对话

配置完成后，重启您的客户端或在对话框中发送以下提示词进行测试：

```text
帮我查一下杭州市中心明天入住的五星级酒店，预算在 800 元以内，最好带健身房
```

AI 客户端将自动唤起 `rollinggo-hotel` 的 `searchHotels` 工具，并在回答中展示匹配的真实酒店与房型价格卡片。
