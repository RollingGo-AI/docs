个人用户通道专为希望在自己的个人 AI 编程工具或桌面智能体中直接调用酒旅预订、房型查询与票务比价的用户设计。无需繁杂的注册与企业资质认证，一键生成配置包与安装命令，随取随用。

## 支持的客户端与智能体

<CardGroup cols={3}>
  <Card title="Cursor IDE" icon="terminal">
    在 Cursor 设置中的 MCP 模块直接黏贴生成的 JSON 配置。
  </Card>

  <Card title="Claude Code / Desktop" icon="robot">
    在 `claude_desktop_config.json` 中添加 RollingGo travel tools。
  </Card>

  <Card title="OpenClaw / CLI" icon="bolt">
    支持通过统一的标准命令行一键拉取并安装运行。
  </Card>
</CardGroup>

## 快速使用

<Steps>
  <Step title="打开个人用户通道">
    在 [RollingGo 合作伙伴中心](https://rollinggo.store/zh) 点击 **个人用户 (Personal)** 卡片。
  </Step>
  <Step title="选择日常使用的 AI 工具">
    选择您正在使用的客户端（Cursor / Claude / OpenClaw 等）。
  </Step>
  <Step title="复制配置代码并粘贴生效">
    页面将为您生成适配该客户端的配置片段（JSON 或 Shell 命令）。将代码复制并粘贴到您的客户端配置文件中保存，即可在聊天对话中直接询问“帮我查一下杭州西湖附近的五星级酒店”！
  </Step>
</Steps>
