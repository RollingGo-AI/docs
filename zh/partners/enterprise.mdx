企业合作伙伴适用于希望将 RollingGo 酒旅 MCP 产品与搜索预订能力深度集成到内部 OA、企业差旅系统、员工福利门户或面向客户的商业化产品的企业与机构。表单提交瞬间即可完成激活：专属 API Key 与 MCP 连接参数即时显示在屏幕上，初始密码直接发至注册邮箱。全自动化，零人工审批等待。

## 入驻流程

<Steps>
  <Step title="打开企业合作通道">
    访问 [RollingGo 合作伙伴中心](https://rollinggo.store/zh)，点击 **企业合作 (Enterprise)** 卡片。
  </Step>
  <Step title="选择所属地域">
    选择 **中国大陆** 或 **国际 / 港澳台**。此选项提交后永久生效，决定了 API 服务端点与计费币种。

    | 地域 | 服务节点 | 结算币种 |
    | --- | --- | --- |
    | 中国大陆 | rollinggo.cn | CNY (人民币) |
    | 国际 / 港澳台 | rollinggo.ai | USD (美元) |

    <Warning>
      地域绑定提交后不可更改，请根据企业实际业务与结算货币审慎确认。
    </Warning>
  </Step>
  <Step title="填写企业资料">
    填写表单中的必要项：
    - **企业法定名称**：与营业执照一致的完整企业名称
    - **统一社会信用代码**：18 位法人和其他组织统一社会信用代码
    - **已有线上产品**：当前是否有已上线运行的产品/平台（是 / 否）
    - **预估每日调用量**：预计每日接口调用规模
    - **应用场景描述**：简要说明拟集成的业务场景与产品形态
    - **是否属于旅游行业**：主营业务是否包含酒旅相关（是 / 否）
    - **联系人姓名**：企业对接负责人全名
    - **手机号码**：包含国际区号（如 +86）
    - **企业邮箱**：作为后续登录合作伙伴中心的唯一账号
    - **邮箱验证码**：点击“发送验证码”，输入邮件收到的 6 位 OTP
  </Step>
  <Step title="提交并获取企业凭证">
    点击 **提交**。页面即刻生成专属 **API Key** 与 **MCP 连接参数**。离开前请妥善复制并留存。
  </Step>
  <Step title="通过邮件密码登录管理后台">
    查收来自 RollingGo 合作伙伴中心的邮件，使用邮件中的 **初始密码** 登录后台，可进行额度查看、秘钥轮转与账单管理。
  </Step>
</Steps>
