开发者身份适用于独立开发者、初创技术团队或开源创作者。无论是为大模型 Agent 赋予酒旅搜索预订能力，还是构建旅行比价工具、定制路线规划产品，开发者通道均可在注册完成后秒级返回 API Key，免去繁琐资质审核。

## 注册步骤

<Steps>
  <Step title="打开开发者注册通道">
    在 [RollingGo 合作伙伴中心](https://rollinggo.store/zh) 点击 **开发者 (Developer)** 卡片。
  </Step>
  <Step title="选择地域">
    选择 **中国大陆**（CNY 计费）或 **国际 / 港澳台**（USD 计费）。根据拟调用的服务节点与 API 网关进行确认。
  </Step>
  <Step title="填写基本信息">
    输入开发者称呼/团队名、联系邮箱、意向构建的产品场景，并通过邮箱验证码校验。
  </Step>
  <Step title="获取 API Key">
    点击提交，屏幕立即返回专属 **API Key**。
  </Step>
  <Step title="查收初始账号密码">
    登录邮箱查看由系统投递的初始登录密码，登录后台即可查看调用配额与流量日志。
  </Step>
</Steps>
