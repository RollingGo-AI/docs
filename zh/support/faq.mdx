## 入驻与开通

<AccordionGroup>
  <Accordion title="入驻真的不需要人工审核吗？">
    是的。RollingGo 合作伙伴中心全链路实行全自动化秒级审核。只要填写的企业信息（如统一社会信用代码）格式合规，且邮箱验证码通过，提交瞬间即可获得对应凭证与开通账号，无需排队等待人工审批。
  </Accordion>

  <Accordion title="注册时选错了地域可以更改吗？">
    地域绑定提交后在系统底层是不可直接更改的。如果您需要切换地域（如从中国大陆切换到国际站），请使用另一个邮箱重新注册对应地域的账号。
  </Accordion>

  <Accordion title="个人用户和开发者有什么区别？">
    个人用户无需注册管理后台账号，可直接复制配置片段将 MCP 技能加入 Cursor 或 Claude Code 等本地 AI 工具中；开发者则享有专属控制台、独立 API Key、更高并发调用配额与完整的调用统计分析。
  </Accordion>
</AccordionGroup>

## 接口调用与配额

<AccordionGroup>
  <Accordion title="初始 API 调用额度是多少？">
    新注册的开发者账号默认提供充裕的开发测试配额。如企业业务需要更高的并发调用量或定制 QPS 上限，可在后台提交工单申请扩额。
  </Accordion>

  <Accordion title="调用出现 401 Unauthorized 错误怎么办？">
    请检查 HTTP 请求头是否正确携带了 `Authorization: Bearer <YOUR_API_KEY>`，并确保调用的接口域名（国内站 `api.rollinggo.cn` vs 海外站 `api.rollinggo.ai`）与您的 API Key 归属地域一致。
  </Accordion>
</AccordionGroup>

## 达人分销与收益

<AccordionGroup>
  <Accordion title="推广链接如何确定是我的订单？">
    每个达人都有独一无二的 Channel ID。用户首次通过您的链接进入后，系统会建立为期 30 天的会话归因记录。只要用户在有效期内履约完成，佣金均自动归属于您的账户。
  </Accordion>

  <Accordion title="佣金何时可以提现？">
    用户实际入住并退房离店后的 7 个工作日内，系统将自动核算并将预估佣金转为可提现金额。支持绑定银行卡对公或对私结算。
  </Accordion>
</AccordionGroup>
