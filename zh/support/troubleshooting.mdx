本篇汇总了在入驻、配置及调用过程中可能遇到的各类异常情况与排查解决手段。

## 注册与登录排查

<AccordionGroup>
  <Accordion title="收不到邮箱动态验证码 (OTP)">
    1. **检查垃圾箱**：部分企业邮箱的反垃圾过滤机制可能将验证邮件归入“垃圾箱”或“订阅邮件”。<br/>
    2. **检查发件人**：发件地址为 `partner@rollinggo.cn` 或 `partner@rollinggo.ai`，请将此域名加入白名单。<br/>
    3. **避免频繁点击**：验证码每 60 秒可重新触发一次，建议耐心等待 10-20 秒后再查收。
  </Accordion>

  <Accordion title="统一社会信用代码校验失败">
    统一社会信用代码必须为符合国家标准的 18 位阿拉伯数字或大写英文字母（不含 I、O、Z、S、V 等易混淆字符）。请从营业执照或官方“国家企业信用信息公示系统”中直接核准复制。
  </Accordion>
</AccordionGroup>

## API 与 MCP 联调排查

<AccordionGroup>
  <Accordion title="401 Unauthorized / Token Expired">
    - 确认请求头部携带了正确的 `Authorization: Bearer <KEY>` 格式；
    - 确认调用的域名与秘钥地域一致：中国大陆调用 `https://api.rollinggo.cn`，国际站调用 `https://api.rollinggo.ai`。
  </Accordion>

  <Accordion title="MCP WebSocket 连接超时 (ECONNREFUSED / ETIMEDOUT)">
    - 确认客户端到 `wss://mcp.rollinggo.cn/v1` 的 443 端口网络通畅；
    - 若在公司内部防火墙内运行，请配置相应的代理例外。
  </Accordion>
</AccordionGroup>
